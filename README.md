# astrochan-blog

A minimalist personal technical blog built with Hugo.

The project follows a plain-files-first model: Markdown is the source, Hugo
generates static HTML, and CSS carries the visual identity. The structure is
inspired by the restraint and document-like feel of mitchellh.com, while the
design direction is intentionally its own. Its colors adapt Monkeytype's 80s
After Dark palette into a calm reading surface: deep indigo, pale text, pink,
blue, and a restrained yellow highlight. Atkinson Hyperlegible is bundled
locally and used for the interface and reading typography.

## Local development

Install Hugo, then run:

```sh
hugo server --buildDrafts
```

Build the static site with:

```sh
hugo
```
